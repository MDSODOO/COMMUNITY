# Audio Notification File

Place your notification sound file here as:

    bi_pos_stock/static/src/audio/notification.mp3

Requirements:
- Format: MP3 or WAV (MP3 recommended for size)
- Duration: 0.5 – 2 seconds
- Volume: normalized (not too loud)

The JS code references: `/bi_pos_stock/static/src/audio/notification.mp3`

If the file is missing, the popup still appears — the Audio API error is caught silently.

Free sources for royalty-free notification sounds:
- https://mixkit.co/free-sound-effects/notification/
- https://freesound.org (search "notification")
